💡 How FIFO Works in This Application:

When you submit a document, the C engine calls queue_enqueue() which places it at jobs[rear]. When you click "Print Next Job", the C engine calls queue_dequeue() which extracts jobs[front] (the earliest arrived document) and shifts all subsequent pending jobs forward by one position so no array slots are wasted.
